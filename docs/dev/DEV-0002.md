## DEV-0002-03 3D 任务服务端（2026-11-12）

### 1. 目标与边界

- 新建云函数 `sinn-model3d`，实现 SPEC-0002 §B.1/§B.2 的 API-02-01..05（submit/get/list/delete/deleteAll），统一响应信封 `{ok,data,error|null,requestId,serverTime}`。
- 新建 `Model3dVendorAdapter` 抽象（submit/query/fetchAsset/health），默认 `mock`；`tripo` 只留骨架（真实调用本次不发起，预算留给 SPIKE-0002C）。
- 数据模型复用 P1 `sinn_users / sinn_tasks / sinn_assets`，新增集合 `sinn_models3d`（字段与索引见 SPEC-0002 §B.3）。
- 长任务：服务端默认 300s（`SINN_MODEL3D_TIMEOUT_MS` 覆写），幂等 `(openid, clientReqId)`，同用户并发 1（`2002` + `existingTaskId`）。
- 存储：单模型 GLB 校验魔数 `glTF`、≤45MB，超限 `6003`，失败不写正式记录并清理临时对象；3D 不消耗 2D 额度。
- 扩展 `sinn-cleanup`：失败/超时 3D 任务到期物理删除任务+资产+云存储对象；成功 3D 任务到期只清理输入照片（模型保留），`purgeAt` 置 null。
